# 参数说明

本文档说明程序界面中各参数的含义、作用及建议取值。

---

## 一、数据与公共参数

这些参数描述雷达硬件配置，所有处理模块共用，**必须与实际采集设置一致**，否则距离/速度等计算结果均会出错。

### 起始频率（GHz）

FMCW 调频信号的起始载频，单位 GHz。

用于计算载波波长 λ = c / f₀，进而用于测角（相位差→角度）等计算。
默认值 **75 GHz** 对应毫米波 AWR 系列雷达。

### 斜率（MHz/μs）

调频斜率，即单位时间内频率的变化量，单位 MHz/μs。

决定雷达带宽和距离分辨率：

```
带宽 B = 斜率 × 采样点 / 采样率
距离分辨率 = c / (2B)
```

斜率越大，带宽越大，距离分辨率越好。

### 采样率（ksps）

ADC 采样率，单位 ksps（千采样点/秒）。

影响每个 chirp 可观测的最大拍频，进而决定最大不模糊距离：

```
最大距离 = c × 采样率 / (4 × 斜率)
```

默认值 **3000 ksps**。

### 采样点

每个 chirp 内 ADC 采集的样本数。

与斜率、采样率共同决定有效带宽和距离分辨率。一般直接从雷达配置工具读取，不要随意修改。

默认值 **256**。

### Chirp/帧

每帧包含的 chirp 数量。

影响慢时间维度长度，进而影响多普勒/速度分辨率。帧内 chirp 越多，速度分辨率越好。

默认值 **8**。

### 帧周期（ms）

相邻帧之间的时间间隔，单位毫秒。

用于将帧索引转换为实际时间轴（测速时生成时间序列）。需与雷达采集配置一致。

默认值 **500 ms**。

### 数据格式

bin 文件的原始数据排列格式。选择"自动"时程序会根据文件大小和参数推断格式。
若自动识别结果不正确，可手动选择具体格式：

| 格式名 | 说明 |
|---|---|
| 自动 | 程序自动推断 |
| int16 实数 | 每个采样点一个 int16，实数格式 |
| int16 I/Q 交织复数 | I、Q 交替存储，每对构成一个复数采样 |
| int8 16 通道原始帧 | 16 天线通道，每帧带独立帧头，int8 格式 |

### 文件头（bytes）

bin 文件开头需要跳过的字节数。选择"自动"时程序尝试自动检测。
若已知具体文件头大小，填入数值可提高读取可靠性。

### 窗函数

FFT 前对时域信号加权的窗函数类型，用于抑制频谱旁瓣，改善峰值分辨能力。

| 窗函数 | 主瓣宽度 | 旁瓣抑制 | 适用场景 |
|:---:|:---:|:---:|---|
| rect（矩形） | 最窄 | 最差（-13 dB） | 不关心旁瓣时用 |
| hann | 中等 | 好（-32 dB） | 通用 |
| **hamming（默认）** | 中等 | 较好（-43 dB） | 通用 |
| blackman | 较宽 | 很好（-58 dB） | 强弱目标共存 |
| flattop | 最宽 | 极好 | 幅度精度优先 |
| kaiser | 可调 | 好 | 通用 |

### 补零幂

FFT 补零的倍数控制参数。在信号末尾填充零，使 FFT 点数翻倍（每增加 1，FFT 点数翻一倍）。

补零不增加频率分辨率（信息量不变），但通过插值让频谱曲线更平滑，峰值位置估计更精细。

| 补零幂 | FFT 点数（采样点 256 时） | 相对不补零的插值倍数 |
|:---:|:---:|:---:|
| 0 | 256 | ×1 |
| 1 | 512 | ×2 |
| 2 | 1024 | ×4 |
| **5（默认）** | **8192** | **×32** |

补零幂越大，读数越精细，计算量也越大。一般保持默认值 **5** 即可。

## 二、帧 / 天线 / Chirp 选择器

这三个选择器在处理每个模块时指定从哪个帧、哪个天线、哪个 chirp 取数据。

| 选择器 | 说明 |
|---|---|
| 帧 | 要处理的帧编号（从 1 开始），读取文件后自动设置上限 |
| 天线 | 选择单个天线通道，或选"平均"对所有通道取平均 |
| Chirp | 选择单个 chirp，或选"平均"对帧内所有 chirp 取平均 |

## 三、测距 / HRRP 模块参数

### 截取比例

对每个 chirp 的采样数据只使用前 `截取比例 × 采样点` 个样本，剩余丢弃。

用于排除采样末尾可能存在的噪声或失真段。取 1.0 表示使用全部采样点。

取值范围 (0, 1]，默认值 **1.0**。

### 目标数

HRRP 图上最多检测并标注的目标峰值数量。

程序按幅度从大到小挑选局部峰，受"忽略近端"和"目标间隔"过滤后取前 N 个。

默认值 **2**。

### 忽略近端（m）

距离小于此值的距离单元不参与目标检测，单位米。

用于屏蔽天线近场、机壳反射等强干扰，避免误判为目标。

默认值 **0.15 m**。

### 目标间隔（m）

两个检测目标之间的最小距离间隔，单位米。

用于防止同一宽峰被重复标注为多个目标。间隔越小，允许识别距离更近的多目标。

默认值 **0.15 m**。

## 四、测距精度模块参数

本模块同时用全带宽和半带宽两套 HRRP 估计测距精度，精度公式为：

```
σ = (√3 / (π√(2·SNR))) × 距离分辨率
```

### 忽略近端（m）

同"测距 / HRRP"模块，屏蔽极近处的强反射，默认 **0.15 m**。

### 噪声最大距离（m）

用于估计噪声功率的最大距离范围，单位米。程序将此距离内排除目标区域后的剩余单元当作噪声。

留空时自动使用雷达最大可测距离。

### 保护单元

目标峰两侧在计算噪声时额外排除的距离格数（格 = FFT 距离分辨格）。

用于防止目标旁瓣泄漏到噪声估计区，避免 SNR 被低估。值越大，对宽目标的保护越充分，但噪声样本越少。

默认值 **8**。

### 全带宽窗 / 半带宽窗

分别为全带宽 HRRP 和半带宽 HRRP 使用的窗函数。

窗函数选择影响旁瓣高度，进而影响噪声估计精度。两个案例可以用不同窗函数对比分析。

## 五、测速模块参数

### 最小距离 / 最大距离（m）

目标跟踪的距离搜索范围，单位米。超出此范围的距离单元不参与目标检测和轨迹跟踪。

建议设置为目标运动的实际距离区间，以减少虚警干扰。

### 最大跳变（m/帧）

相邻帧之间目标距离的最大允许变化量，单位 m/帧。

用于轨迹跟踪的状态转移代价计算：超过此值的距离跳变会被认为代价很高，降低被选中的概率。
设置过小会导致快速移动目标被丢失，设置过大会增加跟踪到虚假目标的风险。

默认值 **1.0 m/帧**。

### 置信阈值（dB）

目标峰信噪比（相对于同帧噪声中位值）必须高于此值，该帧才被标记为"有效帧"。

- 值越高：有效帧要求越严格，统计结果更可靠，但有效帧数可能减少
- 值越低：保留更多帧参与统计，但弱信号帧可能引入误差

默认值 **6.0 dB**。

### 平滑帧数

对跟踪轨迹做滑动平均的窗口长度（帧数），用于消除逐帧距离估计的抖动。

值越大，轨迹越平滑，但对快速变化的响应也越滞后。设为 1 或 0 时不做平滑。

默认值 **3**。

### 静态抑制

勾选后，在 FFT 之前对所有帧的距离谱取均值并减去，用于抑制静止杂波（固定反射体）。

静态目标场景（如测量固定墙壁）应**不勾选**；对运动目标测速时建议**勾选**。

### 优先接近目标

勾选后，轨迹跟踪时对距离增大（目标远离）的路径施加额外惩罚，倾向于选择接近雷达的轨迹。

适用于已知目标正在接近的场景，可减少跟踪到后退虚假路径的概率。

## 六、距离-多普勒模块参数

### RD 帧

要显示距离-多普勒图的帧编号（从 1 开始）。

### 播放速度（fps）

距离-多普勒页专用播放速度，单位为每秒帧数。点击 **播放** 后，程序会从当前 **RD 帧** 开始按帧号顺序刷新距离-多普勒图；点击 **停止** 后保留当前 RD 帧。

### 最小 / 最大距离（m）

距离-多普勒图的距离显示范围。

### Chirp 周期（μs）

相邻 chirp 之间的时间间隔（慢时间采样间隔），单位微秒。

用于将多普勒频率转换为速度：

```
速度 = 多普勒频率 × λ / 2
速度分辨率 = λ / (2 × chirp数 × chirp周期)
最大无模糊速度 = λ / (4 × chirp周期)
```

此值需从雷达配置中获取，填错会导致速度轴刻度错误。默认值 **100 μs**。

### Doppler FFT

多普勒维 FFT 点数。点数越大，速度轴分辨率越细，但计算量增加。

默认值 **128**。

### 速度范围（m/s）

距离-多普勒图速度轴的显示上限（正负对称），超出范围的速度单元不显示。

默认值 **2.5 m/s**。

### 慢时间

构建慢时间维度的方式：

| 选项 | 说明 |
|---|---|
| **天线 × Chirp（默认）** | 将所有天线的所有 chirp 展开拼接，慢时间样本数 = 天线数 × chirp 数，多普勒分辨率最好 |
| Chirp | 对天线取平均后，以各 chirp 为慢时间，样本数 = chirp 数 |

### 静态抑制

同测速模块，对帧内各慢时间单元减去均值，抑制零速附近的静态杂波。

## 七、测角模块参数

### 虚拟通道

参与测角计算的 8 个天线通道编号，用逗号分隔，例如 `1,2,3,4,5,6,7,8`。

这 8 个通道被当作一个等间距虚拟线阵（ULA）处理。通道顺序决定阵列方向，填错会导致角度符号相反或谱图失真。

### 阵元间距（mm）

相邻虚拟阵元之间的实际物理距离，单位毫米（程序内部自动换算为米）。

用于将相邻通道的相位差 Δφ 换算成方位角 θ：

```
sin(θ) = λ · Δφ / (2π · d)
```

填错会导致测出的角度整体偏大或偏小。为避免测角模糊，要求 d ≤ λ/2（半波长条件）。

| 载频 | 半波长参考值 |
|:---:|:---:|
| 75 GHz | ≈ 2.0 mm |
| 77 GHz | ≈ 1.95 mm |
| 24 GHz | ≈ 6.25 mm |

默认值 **2.0 mm**，请按实际天线设计填写。

### 方位 FFT

对 8 个通道做角度 FFT 时的点数，用于生成角谱和距离-角度图。点数越大，角谱插值越细。

默认值 **256**。

### 忽略近端（m）

距离小于此值的单元不参与测角目标检测，用于屏蔽近场干扰。默认 **0.15 m**。

### 显示最大距离（m）

距离-角度图的距离轴上限，超出部分不显示也不参与 CFAR 检测。

### CFAR 距离间隔（m）

两个检测目标在距离维的最小间隔，用于去重，防止同一目标被重复报告。默认 **0.15 m**。

### CFAR 角度间隔（度）

两个检测目标在角度维的最小间隔，与距离间隔配合使用（两个条件需同时满足才去重）。默认 **5.0°**。

### 最大目标数

CFAR 最多输出的检测目标数。按功率降序取前 N 个。

### 训练距 / 保护距 · 训练角 / 保护角

定义 2D CA-CFAR（单元平均恒虚警）检测器的滑窗结构。

程序在距离-角度图上对每个单元估计背景噪声：以待测单元为中心，取外框（训练区）减去内框（保护区）的平均功率作为噪声估计。

```
┌─────────────────────────────┐
│        训练区（外框）         │  ← 训练距 / 训练角 决定外框半径
│   ┌─────────────────────┐   │
│   │     保护区（内框）    │   │  ← 保护距 / 保护角 决定内框半径
│   │   ┌─────────────┐   │   │
│   │   │  待检测单元  │   │   │
│   │   └─────────────┘   │   │
│   └─────────────────────┘   │
└─────────────────────────────┘
```

| 参数 | 含义 | 单位 |
|---|---|:---:|
| 训练距 | 距离维训练单元数（外框半径） | 格 |
| 保护距 | 距离维保护单元数（内框半径） | 格 |
| 训练角 | 角度维训练单元数（外框半径） | 格 |
| 保护角 | 角度维保护单元数（内框半径） | 格 |

保护区防止目标旁瓣污染噪声估计；训练区越大噪声估计越稳定。

默认：训练距 **8**、保护距 **2**、训练角 **6**、保护角 **2**。

### 阈值（dB）

CFAR 判决额外余量：待测单元功率须高于噪声估计 `threshold_dB` 才被判为目标。

```
检测条件：cell_power ≥ noise_power × 10^(threshold_dB / 10)
```

- 值越大：检测保守，虚警少、漏检多
- **0.0 dB（默认）**：高于估计噪声均值即报告目标
- 值为负：检测激进，漏检少、虚警多

出现大量虚假目标时，可调高至 3～10 dB。

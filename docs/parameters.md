# 参数说明

## 公共参数

### 补零幂

FFT 在做频谱分析前，会在信号末尾填充若干个零（补零），使 FFT 点数变大。
补零本身不增加信息量，但能对频谱进行**插值细化**，让峰值定位更准确，图形曲线更平滑。

**补零幂** 控制 FFT 点数在"恰好能容纳采样点数的 2 的幂次"基础上，额外再翻几倍：

| 补零幂 | FFT 点数（采样点 256 时） | 说明 |
|:---:|:---:|---|
| 0 | 256 | 不额外补零 |
| 1 | 512 | 插值 ×2 |
| 2 | 1024 | 插值 ×4 |
| 5（默认）| 8192 | 插值 ×32，精度与速度的合理折中 |

补零幂越大，距离/速度读数越精细，但计算量也随之增加。一般保持默认值 **5** 即可。

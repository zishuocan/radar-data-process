# Radar App — FMCW 雷达 bin 文件处理程序

统一的 FMCW 雷达 `.bin` 文件桌面处理程序,提供完整的雷达信号处理链路：数据读取、测距、测距精度分析、测速、距离-多普勒图、测角等功能。

采用 Python + tkinter 构建原生 GUI，无需 Web 服务或第三方运行时。

---

## 功能模块

| 模块 | 功能 | 说明 |
|------|------|------|
| **测距 / HRRP** | 一维高分辨距离像 | 去直流→加窗→FFT→抛物线插值峰值定位，支持多目标检测、3dB 宽度测量 |
| **测距精度** | 距离估计精度分析 | 全带宽与半带宽两种配置对比，CRLB 理论精度计算 |
| **测速** | 运动目标速度估计 | 维特比动态规划轨迹跟踪，多帧联合优化，平滑滤波 |
| **距离-多普勒** | 距离-速度二维图 | 慢时间 Doppler FFT，速度分辨率与最大无模糊速度自动计算 |
| **测角** | 目标角度估计 | 相位法 + FFT 波束形成 + 2D CA-CFAR 多目标检测 |

### 测角方法详解

1. **相位法** — 相邻虚拟通道的相位差通过 arcsin 映射到角度，计算极快
2. **FFT 法（数字波束形成）** — 8 通道复向量补零加窗做 FFT，峰值对应目标角度
3. **2D CA-CFAR** — 距离-角度二维平面恒虚警检测，支持多目标

支持 0° 校准文件补偿通道间固有相位差。

## 使用流程

### 1. 数据与公共参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 起始频率 | FMCW 起始频率 (GHz) | 75 |
| 调频斜率 | Chirp 调频斜率 (MHz/μs) | 30 |
| 采样率 | ADC 采样率 (ksps) | 3000 |
| 采样点 | 每 Chirp 采样点数 | 256 |
| Chirp/帧 | 每帧包含的 Chirp 数 | 8 |
| 帧周期 | 每帧时间间隔 (ms) | 500 |
| 数据格式 | bin 文件编码格式 | 自动识别 |
| 文件头 | 文件头字节数 (bytes) | 自动检测 |
| 窗函数 | FFT 加窗类型 | hamming |
| 补零幂 | FFT 补零倍数控制 | 5 |

支持的 bin 格式：

- `int8_ant16` — int8 16 通道原始帧（带帧头 8 字节）
- `iq_int16` — int16 I/Q 交织复数
- `int16_real` — int16 实数
- `uint16_real` — uint16 实数

程序会**自动遍历**所有格式和候选文件头大小，选择帧对齐最完整的匹配项。

### 2. 选择文件

点击 **选择** → 选取 `.bin` 文件 → 程序自动识别格式并读取。

### 3. 模块处理

切换标签页 → 设置模块参数 → 点击 **处理当前模块**。

### 4. 结果导出

- **保存当前结果** — 导出 PNG 图片 + CSV 汇总 + 参数配置
- **设为测角校准** — 将当前测角结果保存为 0° 相位校准

### 5. 交互操作

- **单击图片上的数据点** — 显示精确数值标注
- **右键单击图片** — 清除所有标注
- **双击测角子图** — 弹出独立放大窗口（带 Matplotlib 工具栏）

## 参数说明

### 补零幂

FFT 补零不增加信息量，但能对频谱进行插值细化，让峰值定位更准确：

| 补零幂 | FFT 点数（采样点 256 时） | 说明 |
|:---:|:---:|---|
| 0 | 256 | 不额外补零 |
| 1 | 512 | 插值 ×2 |
| 2 | 1024 | 插值 ×4 |
| 5（默认） | 8192 | 插值 ×32，精度与速度的合理折中 |

### 测距 / HRRP 参数

| 参数 | 说明 |
|------|------|
| 截取比例 | 对采样点尾部截断比例（抗干扰） |
| 目标数 | 最大检测目标数量 |
| 忽略近端 | 忽略该距离以内的峰值（消除近场杂波） |
| 目标间隔 | 两个独立目标的最小距离间隔 |

### 测距精度参数

| 参数 | 说明 |
|------|------|
| 忽略近端 | 目标搜索起始距离 |
| 噪声最大距离 | 噪声估计范围上限 |
| 保护单元 | 目标 3dB 主瓣外的保护单元数 |
| 全带宽窗 / 半带宽窗 | 两种带宽配置使用不同的窗函数 |

### 测速参数

| 参数 | 说明 |
|------|------|
| 最小/最大距离 | 目标搜索距离范围 |
| 最大跳变 | 相邻帧间目标最大移动距离 |
| 置信阈值 | 峰值的信噪比阈值（dB） |
| 平滑帧数 | 轨迹平滑滑动窗口大小 |
| 静态抑制 | 启用后减去所有帧的均值，抑制静止杂波 |
| 优先接近目标 | 在代价函数中偏向距离减小的方向 |

### 测角参数

| 参数 | 说明 |
|------|------|
| 虚拟通道 | 8 个虚拟通道编号，用逗号分隔 |
| 阵元间距 | 相邻虚拟天线间距 (mm) |
| 方位 FFT | 角度 FFT 点数 |
| CFAR 距离/角度间隔 | 多目标检测的最小间隔 |
| 训练距/角 | CFAR 训练单元数 |
| 保护距/角 | CFAR 保护单元数 |
| 阈值 | CFAR 检测门限 (dB) |

## 算法要点

### 抛物线插值

对 FFT 峰值及其左右两点做二次插值，突破离散栅格限制，提高距离/角度估计精度。

### 维特比轨迹跟踪

在距离-时间平面上，将多帧峰值检测建模为动态规划问题：每帧候选点之间的转移代价 = 距离跳变惩罚 + 方向偏置，全局最优路径即为目标轨迹。

### 2D CA-CFAR

使用积分图像在 O(1) 时间内完成任意矩形区域的噪声功率估计，在距离-角度二维平面上逐像素检测目标，支持保护单元抑制目标泄漏。

### 自适应格式识别

穷举数据格式 × 文件头大小组合，按帧对齐完整性评分，自动选择最优配置。
